# توقيع نسخة الإصدار

ملف APK النهائي يحتاج مفتاح توقيع خاص يملكه صاحب التطبيق. لا تضع ملف المفتاح أو كلمات مروره داخل المشروع أو Git، ولا تشاركها عبر المحادثة.

تم إنشاء مفتاح إصدار خاص بهذا التطبيق في مجلد OMEGA/Signing داخل LocalAppData لحساب Windows الحالي. ملف omega-attendance-release.p12 هو المفتاح، وملف signing-password.dpapi يحتوي كلمة مروره مشفّرة بحماية Windows لهذا الحساب. لا تعتمد على ملف DPAPI وحده لاستعادة المفتاح على جهاز Windows آخر.

لإظهار كلمة المرور محليًا وتدوينها في مدير كلمات مرور أو ورقة محفوظة بأمان، شغّل scripts/Show-OmegaSigningPassword.ps1 في نافذة PowerShell الخاصة بك وأدخل REVEAL عند الطلب. لا ترسل الكلمة عبر المحادثة. احتفظ بنسختين مستقلتين من ملف المفتاح، وبكلمة المرور في مكان منفصل. بعد ذلك يمكن بناء تحديثات موقّعة عبر scripts/Build-OmegaRelease.ps1.

يقرأ Gradle إعدادات التوقيع من متغيرات البيئة التالية:

OMEGA_RELEASE_STORE_FILE
OMEGA_RELEASE_STORE_PASSWORD
OMEGA_RELEASE_KEY_ALIAS
OMEGA_RELEASE_KEY_PASSWORD

بعد ضبطها، نفّذ أمر Gradle assembleRelease وتحقق من توقيع الملف الناتج باستخدام apksigner verify --verbose --print-certs. سكربت البناء أعلاه يضبط المتغيرات مؤقتًا من الملف المحمي، ويبني دون configuration cache أو daemon دائم، ويتحقق من توقيع APK تلقائيًا. فقدان المفتاح أو كلمة مروره يمنع إصدار تحديث متوافق مع نفس التطبيق المثبّت.

النسخ التجريبية السابقة موقّعة بمفتاح debug. لا يمكن تحديثها مباشرة بنسخة موقّعة بمفتاح إصدار جديد. عند الانتقال إلى الإصدار النهائي يلزم إزالة النسخة التجريبية أولًا، ما يمسح بياناتها المحلية. لا تُزل نسخة تحتوي بيانات حقيقية قبل حفظ نسخة قابلة للاستعادة والتحقق منها.
